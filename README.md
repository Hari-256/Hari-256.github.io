# Hari Krishna Kothapalli · Personal Website

Portfolio and blog of Hari Krishna Kothapalli, Software Engineer at Nokia (Java, microservices, IAM/PAM).

Live site: https://hari-256.github.io · [LinkedIn](https://www.linkedin.com/in/hari-krishna-kothapalli-96623919b/)

- `index.html`: portfolio home page (about, experience, skills, awards, writing, contact)
- `blog.html`: essay, "Five Years at Nokia: Lessons from Building Secure Java Frameworks"
- `404.html`: custom not-found page
- `style.css`: design system, dark and light themes, layout and animations
- `main.js`: theme toggle, scroll reveals, scroll spy, typing effect, count-ups, card spotlight and tilt

Plain HTML, CSS and JavaScript with no build step, hosted for free on GitHub Pages.
